# Docker images

- [Nginx CrowdSec Bouncer](nginx-crowdsec-bouncer/README.md): Run Nginx with CrowdSec protection using an existing CrowdSec Local API. See the linked README for setup and usage.
- [Rsync Receiver](rsync-receiver/README.md): Receive rsync backups over SSH with restricted upload access. See the linked README for setup and usage.
- [Rsync Source](rsync-source/README.md): Let clients pull files over SSH, with optional removal of copied source files. See the linked README for setup and usage.
